Charlie

Charlie is a private household assistant used only by Chen and Roei Amos. It is not offered to the public, and no one else can sign in.

Privacy policy

With each person's consent, Charlie reads that person's own Gmail in read-only mode. It does this to suggest household tasks such as bills, appointments, insurance claims and returns. It never sends, deletes, or changes email.

Data is processed and stored on the household's own computer. Charlie keeps only short extracted details: summaries, dates, amounts, and message IDs. It does not keep copies of email bodies. Data is never sold or shared with anyone. To classify a message, the text is sent to an AI model provider under the household's own account.

Charlie's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Either person can revoke access at any time at myaccount.google.com/permissions.
